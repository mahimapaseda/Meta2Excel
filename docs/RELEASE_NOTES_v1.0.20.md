# Meta Receipts Lite v1.0.20

## UI refresh

- Reworked the Windows desktop window around a light ledger palette with clearer title, version, and primary actions.
- Improved receipt and line-item table contrast, row spacing, and keyboard focus behavior.
- Rewrote the empty state to explain file drop, browsing, and local processing.
- Added access keys and screen-reader descriptions to key controls.

## Downloads

- `MetaReceiptsLite-Setup-v1.0.20.exe` — recommended installer
- `MetaReceiptsLite-v1.0.20.zip` — portable app with dependencies
- `SHA256SUMS-v1.0.20.txt` — release asset checksums

## Requirements

Windows 10/11 and .NET Framework 4.8. The installer does not require administrator rights.
