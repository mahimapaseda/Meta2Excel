# Meta Receipts Lite v1.3.0

## Native Modern UI Overhaul

- **Signature Brand Header**: Restored the clean deep navy brand header (`#1F4E78`) and dedicated dark slate action bar (`#183E60`), eliminating awkward double-title bars and washed-out buttons.
- **Refined Typography**: Integrated clean **Segoe UI** typography (`15pt Bold` title, `9.5pt` section labels, `9pt Bold` table headers) with crisp native rendering.
- **Enhanced Data Grids**: High-contrast navy table headers (`#1F4E78`), generous row heights (`28px`), and subtle row padding.
- **Polished Drop Zone**: Anti-aliased rounded dashed container with vibrant accent feedback upon PDF drag-and-drop.
- **Clean Action Controls**: Distinct green `Add PDFs...` primary action, steel blue export actions, and unified button padding.
