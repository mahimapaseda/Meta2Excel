# Meta Receipts Lite v1.1.0

## Appearance

- Added a light/dark mode control to the desktop toolbar.
- Applied coordinated theme colors to the main window, receipt and line-item tables, filters, and empty state.
- Saved the selected appearance for the next launch; light mode remains the default.

## Downloads

- `MetaReceiptsLite-Setup-v1.1.0.exe` — recommended installer
- `MetaReceiptsLite-v1.1.0.zip` — portable app with dependencies
- `SHA256SUMS-v1.1.0.txt` — release asset checksums

## Requirements

Windows 10/11 and .NET Framework 4.8. The installer does not require administrator rights.
