# Meta Receipts Lite v1.2.0

## Modern Desktop UI Redesign

- **Typography & Hierarchy**: Integrated crisp Segoe UI typography across brand header, drag-and-drop zone, section headers, and data grids.
- **Rounded Action Buttons**: Replaced standard WinForms buttons with anti-aliased, rounded-corner interactive buttons (`ThemeButton.cs`) with active hover, pressed, and focus states.
- **Theme Palette Polish**: Refined dark and light color tokens (`ThemePalette.cs`) with deep slate dark mode, high-contrast text, clear table selection highlights, and emerald accenting.
- **Redesigned Drop Zone**: Upgraded the file staging area with a dashed rounded-corner boundary and dynamic accent feedback on drag-over.
- **Data Grid Ergonomics**: Expanded row heights to 32px with alternating row shading for comfortable ledger browsing.
- **Updater Dialog Modernization**: Styled the in-app software updater with matching rounded action buttons and clean typography.
